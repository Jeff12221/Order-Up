# Order-Up

**A restaurant menu web app for seamless, modern ordering.**

Author: Owheya Jeffrey-Lee

---

## About

Order-Up gives customers a seamless and modern way to order at a restaurant, while also helping restaurants organize and manage incoming customer orders.

It's designed for restaurants who want a modern way to book clients' meals.

## How It Works

The app has three sides that interact with each other whenever an order is placed:

- **Customer** — browses different cuisines and places orders
- **Chef** — receives and prepares placed orders
- **Receptionist** — manages and coordinates orders between customers and the kitchen

## Features

- Browse a variety of cuisines
- Place orders as a customer
- Real-time interaction between customer, chef, and receptionist roles
- Organized order management for restaurant staff

## Tech Stack

- **Frontend:** HTML, CSS
- **Backend:** Python
- **Database:** MongoDB
